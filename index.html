GitHub beállítás (egyszer kell)

A feltöltéssel a darab a tárolóban lévő darabok.txt fájlba kerül, így minden eszközön megjelenik. A kulcs csak ezen az eszközön marad.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → ez a tároló.
  3. Permissions → Contents: Read and write. Generate, majd másold ide.
